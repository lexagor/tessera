What this proves

The broker signed the exact call, principal, policy version and hash, evaluated inputs, tool and arguments hash, broker-held Stripe grant, and the linked broker-observed outcome. The broker re-checked the grant and arguments hash before forwarding exactly one refund request to Stripe test mode. Changing any signed field invalidates the signature or the action-pair link.

What this does not prove

This is a Stripe test-mode call, not a live payment. It does not prove a live customer refund occurred, that the underlying business intent was lawful, or that the provider executed every field correctly. A valid signature proves the signer and bindings, not semantic correctness, and Tessera records are tamper-evident, not tamper-proof.

The static JSON has no bearer-link expiry. The hosted verifier link expires 2026-12-15; use the downloaded JSON after that.
